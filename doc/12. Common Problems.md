```bash
failed to solve: process "/bin/sh -c apt-get update && apt-get upgrade -y &&     apt-get install -y cuda-toolkit libxext6     cuda-tools-12-6 libopenblas0 libcudnn9-cuda-12" did not complete successfully: exit code: 100
```

##### File fix
In Dockerfile replace line 19
```
FROM arlab-base-generic AS arlab-base-gpu
```
with
```
FROM nvidia/cuda:12.6.0-devel-ubuntu24.04 AS arlab-base-gpu

# Install missing apt tools
RUN apt-get update && apt-get install -y software-properties-common
```

In Dockerfile replace line 41-50
```
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked \
    --mount=type=cache,target=/var/lib/apt,sharing=locked \
    wget --quiet -O cuda-keyring.deb https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2404/x86_64/cuda-keyring_1.1-1_all.deb && \
    dpkg -i ./cuda-keyring.deb && \
    rm cuda-keyring.deb
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked \
    --mount=type=cache,target=/var/lib/apt,sharing=locked \
    apt-get update && apt-get upgrade -y && \
    apt-get install -y cuda-toolkit-12-6 libxext6 \
    cuda-tools-12-6 libopenblas0 libcudnn9-cuda-12
```
with
```
# Install only additional packages (CUDA is already present)
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked \
    --mount=type=cache,target=/var/lib/apt,sharing=locked \
    apt-get update && \
    apt-get install -y libxext6 libopenblas0 libcudnn9-cuda-12
```
