## 3.1 Business Context

- Users / Environment:

  - RoboCup referees and audience (evaluate robot’s performance).
  - Human operators and visitors (interact with robot via speech/gesture).
  - Competition arena (navigation, object recognition, task execution).

- System responsibilities:

  - Provide service-robot functions as required by RoboCup @Home.
  - Offer a learning platform for students and researchers.

3.2 Technical Context

- Input interfaces:

  - Sensors (RGB-D camera, LiDAR, microphone array).
  - Network commands (remote operator, debugging).

- Output interfaces:

  - Actuators (drive base, manipulator).
  - Audio output (speech synthesis).
  - Status/logging via ROS2 topics and monitoring tools.
