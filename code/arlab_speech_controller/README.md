# ARLAB speech controller

This package provides speech synthesis and audio processing capabilities for the robot.

## Package structure

```txt
arlab_speech_controller/
├── arlab_speech_controller/
│   └── moshi_tts_node.py     # MOSHI TTS node entry point
├── launch/                   # Launch files
└── requirements.txt          # Python dependencies (PyAudio, MOSHI, etc.)
```

## Key features

- MOSHI text-to-speech integration
- Audio input/output handling with PyAudio
- Speech synthesis for robot communication
