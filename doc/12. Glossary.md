# 12. Glossary
<!-- Important domain and technical terms that stakeholders use when discussing the system. Also: translation reference if you work in a multi-language environment. -->

To ensure a shared understanding, this glossary defines the key terms used in this document and the project. It helps all users/stakeholders

- develop an identical understanding of these terms
- avoid ambiguous synonyms and homonyms

| Term   | Definition   |
| ------ | ------------ |
| **YOLO11** | Object detection model family (“You Only Look Once”) used in perception. |
| **PyTorch** | Machine-learning framework forming the basis for YOLO11. |
| **ROS** | Robot Operating System, middleware for communication and control. |
| **AsyncIOExecutor** | ROS extension enabling asynchronous callback execution. |
| **SLAM** | Simultaneous Localization and Mapping, technique for mapping and localization. |
| **LiDAR** | Light Detection and Ranging, sensor for distance and object detection. |
| **LLM (Large Language Model)** | Language model used in HRI, may produce incorrect outputs (“hallucinations”). |
| **IPC** | Inter-Process Communication, mechanism for data/message exchange between processes. |
| **HRI (Human–Robot Interface)** | Interface between human users and the robot. |
