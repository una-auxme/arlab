# 2. Architecture Constraints

## Technical Constraints

| Use-Case      | Constraint                                                                 |
|---------------|----------------------------------------------------------------------------|
| HRI           | Must run on Jetson Nano (limited processing performance, limited RAM, system reaction time for natural interaction must be acceptable) |
| Manipulation  | Hardware compatibility: must support the selected robotic arm and gripper  |
| Manipulation  | Real-time performance: motion control and grasping must meet real-time requirements |
| Manipulation  | Use of MoveIt2 for motion planning                                         |
| Knowledge Base| Hardware compatibility: must support the Jetson platform                  |
| Knowledge Base| Real-time capability: data must be provided with little to no delay        |
| Movement      | Hardware compatibility: must support robot platform incl. omni-wheels, and Jetson |
| Movement      | Real-time capabilities required for safety (react quickly to avoid collisions) |
| Safety        | Hardware compatibility: must support Jetson platform                       |
| Safety        | Real-time capability: safety-critical data must be processed in real-time  |
| Safety        | Emergency Stop: visible, red, easily pressable button only                 |
