- Hardware compatibility - must support the robot platform including omni-wheels. Also must be able to run on the Jetsons

- Real-Time capabilities - necessary to achieve required safety. Robot must be able to react as fast as possible to avoid collision with moving objects & humans

- Real-time capability - Data must be checkt in "real-time"
- Emergency Stop - Stop button must be easily visible and pressable, must be red, only red button
- Redundancy - Safety must be ensured even if individual components fail
- Safe human interaction
