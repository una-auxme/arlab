# 11. Glossary
<!-- Important domain and technical terms that stakeholders use when discussing the system. Also: translation reference if you work in a multi-language environment. -->

To ensure a shared understanding, this glossary defines the key terms used in this document and the project. It helps all users/stakeholders

- develop an identical understanding of these terms
- avoid ambiguous synonyms and homonyms

| Term   | Definition   |
| ------ | ------------ |
| **95th Percentile (p95)** | Metric: 95% of all measured values lie below this threshold (robustness indicator instead of average). |
| **AsyncIOExecutor** | ROS extension enabling asynchronous callback execution. |
| **Auto-Annotation** | Automatic semantic annotation of the map with entities detected by Computer Vision snapshots during a mapping drive. |
| **Cold Start** | Initial system startup until stable operation (e.g., container setup). |
| **Entity** | Object in the knowledge base (e.g. human, pickable, furniture) with pose and type, referenced by a unique id. |
| **Entity Placer** | Node to add entities manually with a pose selected in RViz. |
| **HRI (Human–Robot Interface)** | Interface between human users and the robot. |
| **IPC** | Inter-Process Communication, mechanism for data/message exchange between processes. |
| **ISO/IEC 25010** | Reference model for software quality attributes (e.g., reliability, maintainability). |
| **IoU (Intersection over Union)** | Metric for the quality of bounding boxes. |
| **KPI** | Key Performance Indicator; measurable target value (e.g., latency, recall). |
| **LiDAR** | Light Detection and Ranging, sensor for distance and object detection. |
| **LLM (Large Language Model)** | Language model used in HRI, may produce incorrect outputs (“hallucinations”). |
| **Mapping Drive** | Drive through the environment with SLAM and auto-annotation active to create an annotated map. |
| **PyTorch** | Machine-learning framework forming the basis for YOLO11. |
| **ROS** | Robot Operating System, middleware for communication and control. |
| **SLAM** | Simultaneous Localization and Mapping, technique for mapping and localization. |
| **Snapshot** | Single on-demand run of Computer Vision object detection on the current camera frame, storing the detections in the knowledge base. |
| **TF** | ROS transform system for the relations between coordinate frames (e.g. `map`, `odom`). |
| **World Model** | Internal, consolidated representation of environment and object states. |
| **YOLO11** | Object detection model family (“You Only Look Once”) used in perception. |
